Configuração do Mercado Pago para cobrança recorrente automática

Sistema Navalha Barbearia — Versão 1.0

Visão Geral do Fluxo

O Nubank não tem API própria para cobrança recorrente (assinaturas). O padrão do mercado brasileiro é usar um gateway de pagamento (Mercado Pago ou Asaas) que gerencia a recorrência e deposita o dinheiro na sua conta Nubank.

Cliente Final
Paga via Pix/Cartão no app do Nubank (ou qualquer banco)
→
Mercado Pago
Gerencia assinatura, cobra todo mês, retentativa se falhar
→
Sua Conta Nubank
Recebe transferência automática (TED/Pix) em 1-2 dias úteis
✅ O que você ganha com isso
  • Cobrança automática todo mês — sem correr atrás de cliente
  • Retentativa inteligente se o pagamento falhar (cartão vencido, saldo insuficiente)
  • Cliente paga via Pix pelo app do Nubank (cai na hora)
  • Dinheiro cai na sua conta Nubank (PJ ou PF/MEI) automaticamente
  • Relatórios, split, antecipação de recebíveis — tudo no painel do Mercado Pago

Passo a Passo (≈ 15 minutos)

1. Criar conta no Mercado Pago

  1. Acesse: mercadopago.com.br/ativacao
  2. Escolha o tipo de conta:
    • Pessoa Jurídica — se a barbearia tem CNPJ (recomendado)
    • MEI / Pessoa Física — usa seu CPF
  3. Complete o cadastro: dados da empresa, endereço, validação de identidade (selfie + documento)
  4. Aguarde aprovação (geralmente imediata para PJ, até 24h para PF)
Use o mesmo CNPJ/CPF que está na conta Nubank da barbearia — evita problemas na transferência.

2. Cadastrar a conta Nubank para receber os pagamentos

  1. No painel do Mercado Pago: Configurações (engrenagem) → Dados bancários
  2. Clique em Adicionar conta bancária
  3. Preencha:
    • Tipo: Conta corrente (Nubank PJ) ou Conta poupança (Nubank PF/MEI)
    • Chave Pix: CNPJ (se PJ) ou CPF/email/telefone (se PF/MEI)
    • Titular: Mesmo nome/CNPJ/CPF da conta Mercado Pago
  4. Confirme com o código enviado pelo app do Nubank (notificação push)
  5. Status deve ficar "Verificada" / "Ativa"

3. Obter as credenciais da API

  1. No painel: Desenvolvedores → Credenciais de produção
  2. Copie os 3 valores abaixo:
Access Token (começa com APP_USR-) → MP_ACCESS_TOKEN
Public Key (começa com APP_USR-)  → MP_PUBLIC_KEY
Webhook Secret (gerar novo)       → MP_WEBHOOK_SECRET
Importante: Use a aba "Produção", não "Teste". O Webhook Secret você gera clicando em "Gerar novo" na seção de webhooks.

4. Configurar o Webhook (para o sistema saber quando pagou)

  1. No painel: Desenvolvedores → Webhooks → Novo webhook
  2. URL: https://SEU-DOMINIO.com/api/webhook/mercadopago
    (Substitua SEU-DOMINIO pelo endereço onde o sistema está hospedado, ex: barbearia.seudominio.com)
  3. Eventos a selecionar:
    • payment (pagamento aprovado/recusado)
    • subscription_preapproval (assinatura criada/cancelada)
  4. Salve → será gerado um Webhook Secret — copie esse valor também

5. Enviar as credenciais para o desenvolvedor (você)

Mande apenas estas 4 linhas (pode ser por WhatsApp/e-mail):

MP_ACCESS_TOKEN=APP_USR-XXXXXXXXXXXXXXXXXXXX
MP_PUBLIC_KEY=APP_USR-XXXXXXXXXXXXXXXXXXXX
MP_WEBHOOK_SECRET=WHS_XXXXXXXXXXXXXXXXXXXX
PAGAMENTO_GATEWAY=mercadopago
Nunca compartilhe essas credenciais publicamente (GitHub, sites, chatbots). Trate como senha bancária.

O que NÃO existe (evite promessas falsas)

API direta do Nubank para "débito automático em conta" — não existe abertura para desenvolvedores terceiros.
"Pix agendado recorrente" nativo — o Pix não tem recorrência; precisa de gateway.
Cobrança direta via NuPay sem gateway — NuPay é para e-commerce pontual, não assinaturas gerenciadas.

Checklist Final

  • Conta Mercado Pago criada com CNPJ/CPF da barbearia
  • Conta Nubank vinculada como conta de recebimento (status "Verificada")
  • Credenciais geradas: Access Token, Public Key, Webhook Secret
  • Webhook configurado apontando para https://SEU-DOMINIO.com/api/webhook/mercadopago
  • Credenciais enviadas pro desenvolvedor colocar no .env do sistema

Depois que o desenvolvedor configurar

  1. Sistema faz o deploy no servidor (VPS/Docker)
  2. Teste no modo Sandbox primeiro (o desenvolvedor sabe como)
  3. Cliente final acessa a aba "Planos" no sistema
  4. Clica em "Assinar" → escolhe Pix → abre app do Nubank → aprova
  5. Todo mês: cobrança automática → dinheiro cai na sua conta Nubank
